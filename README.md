# Authentication & RBAC Demo

A synthetic authentication and role-based authorization demonstration with a viewer role and privileged administrator role.

## Features
- Demo login
- Role-aware API responses
- Admin route protection
- Synthetic credentials only
- Automated tests

## Demo accounts
- `admin / demo`
- `viewer / demo`

## Run
```powershell
npm install
npm start
```

Default port: `4003`.
